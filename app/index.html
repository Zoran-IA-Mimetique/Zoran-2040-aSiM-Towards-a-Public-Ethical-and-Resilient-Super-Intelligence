            Synthèse LLM — Claude API

            Sans clé API, ZORAN affiche la loi retenue + ses cadres mais ne synthétise pas de réponse en langage naturel. Avec une clé Anthropic, ZORAN appelle Claude pour composer une réponse cohérente multi-cadres.

            ⚠ La clé est stockée en localStorage et envoyée depuis le navigateur (entête anthropic-dangerous-direct-browser-access). Utilise une clé restreinte / un usage personnel uniquement.
