# 🧠 Lancer Routine Cognitive

Voici l'application **déjà compilée**, prête à l'emploi. Tu n'as **rien à coder**.

---

## ✅ Méthode 1 — La plus simple (recommandée)

Il te faut **Node.js** installé sur ton ordinateur (gratuit : https://nodejs.org).

1. Dézippe ce dossier.
2. Ouvre un terminal **dans ce dossier**.
3. Tape cette seule commande :

   ```
   node serve.mjs
   ```

4. Le terminal affiche :

   ```
   🧠 Routine Cognitive est lancée !
   ➜  Ouvre ton navigateur sur :  http://localhost:5000
   ```

5. Ouvre **http://localhost:5000** dans Chrome ou Edge.
6. (Optionnel) Clique sur l'icône **« Installer »** dans la barre d'adresse
   pour l'ajouter comme une vraie appli sur ton téléphone / bureau. 📱

---

## ✅ Méthode 2 — Sans rien installer

Si tu as déjà Node.js, depuis ce dossier :

```
npx serve dist
```

Puis ouvre l'adresse indiquée (souvent http://localhost:3000).

---

## 📂 Que contient ce paquet ?

- `dist/` … l'application compilée (ce qui s'exécute réellement)
- `serve.mjs` … le mini-serveur pour la lancer (aucune dépendance)
- `LANCER.md` … ce mode d'emploi

---

## ℹ️ Bon à savoir

- **Aucune donnée n'est envoyée sur internet.** Tout reste sur ton appareil.
- Pour les **notifications**, ton navigateur te demandera l'autorisation :
  clique sur « Activer ». (Sur iPhone/Safari, les notifications sont limitées —
  c'est une contrainte d'Apple.)
- Pour **vider/réinitialiser** : dans le navigateur, efface les données du site
  (les 15 routines d'exemple seront rechargées au lancement suivant).

Bonne découverte ! 🌿
